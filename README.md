# 📊 Personal Budget Tracker  
A full-stack application for tracking **expenses** and **income**, built with **Spring Boot**, **React**, and **TanStack Router**.  
It lets users add, edit, delete, and visualize all their budget entries in a clean and intuitive UI.

![App Preview](./image.png)

---

## 🚀 Features

### ✔️ Expenses & Income Management
- Add new income or expense entries  
- Edit existing records inline  
- Delete entries instantly  
- View all transactions in a clean card-based layout  

### ✔️ Modern UI / UX
- Built using **TailwindCSS**  
- Responsive design  
- Smooth single-item edit mode  
- Modal form for adding new entries  

### ✔️ Full REST API (Spring Boot)
- Create (`POST`)
- Update (`PUT`)
- Delete (`DELETE`)
- Fetch budget data (`GET`)

### ✔️ Frontend Routing with TanStack Router
- Type-safe navigation  
- Organized routes  
- Clean structure  

---

## 🛠️ Tech Stack

### **Frontend**
- React + TypeScript  
- TailwindCSS  
- TanStack Router  
- Fetch API  
- Material UI Icons  

### **Backend**
- Java 17  
- Spring Boot  
- Spring Web  
- Service + Controller architecture  
- CORS enabled
